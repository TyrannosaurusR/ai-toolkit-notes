# Inbox（待整理資源）

> **規則**：丟連結 → 加一句話「為什麼留」→ 猜一下主題 → 預判「拆法」。
> **節奏**：每週/雙週回來消化，整理過的打 `[x]` 並連到正式卡。
> **拆法判準**：未來這一點會在「非這篇文章」場合被獨立引用嗎？
> - 會 → 拆出衛星卡
> - 不會 → 留在一張主卡
> - 純資源庫/連結目錄 → 不開卡，丟對應 MOC 末端「資源清單」
> - 如果連拆法都猜不出來，代表還沒消化好，**先不要動它**。
>
> **格式**：
> ```
> - [ ] YYYY-MM-DD https://...
>   - 為什麼留：一句話
>   - 猜主題：#token優化
>   - 拆法：1 張 / 主+N 衛星 / 不開卡
> ```
> 整理完：
> ```
> - [x] YYYY-MM-DD https://...
>   - → 已整理成 [[新卡名]]
> ```
