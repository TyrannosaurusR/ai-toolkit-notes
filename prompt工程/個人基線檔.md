> [!summary] 用途
> 給 [[Prompt-腦清空與排程]]、[[Prompt-臨時重排]] 引用的個人時段／能量／責任基線。每週類似的東西在這寫一次，跑 prompt 時整段複製貼上即可。改變了再回來更新。

## 1. 作息

- 起床：10:00 過後
- 就寢：02:00 過後
- **例外日**：週二、週五 08:00 工程統計 — 實際處理是「硬撐／常遲到／看回放」
  - 這兩天上午**不算高效寫書時段**，排計畫時當低能量處理

## 2. 餐飲時段

- 早餐：彈性，常跳或併午餐
- 午餐：**12:00-13:00**，後面沒課的話會延到 14:00
- 晚餐：**因日不同**
  - 一 18:30-19:30
  - 二 20:30-21:30（探索下課後）
  - 三 20:00 後（打工下班後）
  - 四／五／六／日 17:30-19:30

## 3. 通勤

校外 10-20 分鐘 → **課間建議留校**，回家成本高

## 4. 平均能量曲線

| 時段 | 能量 | 適合什麼 |
| ---- | ---- | ---- |
| 上午 10:00-12:00 | 中偏低（夜貓） | 例行性、低決策任務 |
| 午後 13:00-17:00 | **高（黃金時段）** | 深度學習、主科考試準備 |
| 傍晚 17:00-20:00 | 中 | 中等難度任務、報告寫作 |
| 晚上 20:00-00:00 | 中偏高 | 創意、整理、興趣 |
| 深夜 00:00 後 | 自評 | （視當天而定，原則上不安排正式任務） |

**週末**：週六 18:30-20:20 [跳] 跨域自主實踐（D-Ren仁齋講堂）— 不出席、沒考試、偶爾報告。其餘週六與週日全天空。

### 5.1 出席壓力與考試壓力分類

| 課程 | 出席 | 考試壓力 |
| ---- | :----: | ---- |
| 工程統計（二、五早 8） | 出（常遲到） | 期末會考 |
| 生產計劃（一、三） | 出 | 期末會考（你之前說「比較大」） |
| 線代（二、四） | 出 | 期末會考 |
| 慢壘（一） | 出 | 體育課，無 |
| 搖滾樂（一） | **出** | 無考試，**只有報告** |
| 探索你的可能性（二晚） | **出** | 無考試，**偶爾報告** |
| 資料庫（二午後） | 跳 | 期末會考（你之前說「比較大」） |
| 動物行為學（四午） | 跳 | **題庫制**，期末考前一週讀即可 |
| 會計學（五午後） | 跳 | **5/22 考試** + 期末考 |
| 跨域自主實踐（六晚） | 跳 | 無考試，只有報告 |

### 5.5 跳課時段的自學分配

依「考試壓力」分級，不是每個跳課時段都要鎖死自學：

| 跳課時段 | 平時用途 | 考前切換 |
| ---- | ---- | ---- |
| 週二 14:20-17:20（資料庫）| **平時為自由時段** | 期末前再升級為衝刺 |
| 週四 12:10-14:10（動物行為學）| **平時為自由時段** | 期末考前一週切換為動物行為學題庫 |
| 週五 15:30-18:20（會計學）| **平時可彈性使用**；5/22 考前一週與期末週前固定鎖會計學 | 5/22 前一週 + 6/8-12 前一週 |
| 週六 18:30-20:20（跨域）| **平時自由** | 報告 due 前一週用來寫跨域報告 |

> [!check] 黃金時段重新標記
> **週三整個午後（13:00-18:00）** → 排深度任務，但要留意 18:00 開始打工
> **週四午後 14:10 後** → 大空檔（平時動物行為學不鎖），扣晚餐 17:30-19:30 還有 ~5-6h
> **週五午後** → 9:50-15:30 連續 5.5h，加上跳會計的 15:30-18:20 平時也可彈用，最多接近 8h
> **週六、週日全天** → 建議 50% 休息／興趣、50% 補本週進度（週六晚跨域跳，全天可用）

## 6. 課表外每週固定責任

- **打工**：週三 18:00-20:00（每週 2h）
- **健身**：
  - 週一 21:00-22:00
  - 週三 10:30-12:00
  - 週五 10:30-12:00
  - 共每週 ~4h
- **社團**：不記錄（彈性／不固定）

## 7. 興趣（充電）清單

排計畫時這些是**合法的時段佔位**，不是「可忽略」：

- 整理 AI 工具
- 看影片／串流／動畫
- 玩遊戲
- 非課表的運動／散步
- 和朋友／伴侶見面聊天
- 聽音樂

預設規則：**每日至少安排 30 分鐘其中之一**。

## 8. 本學期 deadline 結構

- **學期**：114 下（2026 年 2-6 月）
- **現在進度**：5 月中（期中考已過）
- **臨近考試**：5/22 左右會計學考試 — 5/15-5/22 為「會計學衝刺週」，週五 15:30-18:20 鎖會計，週三午後、週日視情況增援
- **期末考週**：**6/8-6/12**（5 天集中）
- **期末準備期**：6/1-6/7 為「期末衝刺週」— 主科優先順序（依考試壓力）：
  1. 生產計劃、資料庫（你之前明確說「比較大」）
  2. 線代、工程統計、會計學
  3. 動物行為學（題庫制，最後 2-3 天集中讀）
- **報告類**（沒考試但有 due）：搖滾樂、探索你的可能性（偶爾）、跨域 — 隨報告期限插入
- **每週循環小考／作業**：無

## 9. 每日可用時間（含全部固定責任後）

「自由時段」= 已扣完出席課、固定自學鎖定、健身、打工、餐飲後，可用於本週新任務的時段。

| 日 | 課（出席）| 課外責任 | 固定自學 | 自由時段粗估 |
| ---- | ---- | ---- | ---- | ---- |
| 一 | 5h（生產、慢壘、搖滾）| 健身 21-22 | 0h | **2-3h**（早 08-10 + 晚 18:20-21:00 扣晚餐 = ~1h + 22:00 後 ~3h，但 22:00 後屬深夜）|
| 二 | 4h（工統、線代、探索）| 0 | 0h | **1-2h**（午 12:00-14:20 扣午餐 ~1h + 晚 20:20 後 ~2h 扣晚餐）|
| 三 | 1h（生產 09:00）| 健身 10:30-12 + 打工 18-20 | 0h | **4-5h**（午 12:00-18:00 扣午餐 ~5h + 晚 20:00 後 ~2h，但要扣晚餐）|
| 四 | 1h（線代尾節 11:10-12:00）| 0 | 平時 0h，期末前 2h | **6-8h**（午 12:00 後到就寢，扣晚餐 17:30-19:30 = 2h）|
| 五 | 2h（工統 8-10）| 健身 10:30-12 | 平時可彈、考前 3h | **5-7h**（午 12:00-15:30 + 15:30-18:20 彈用 + 晚 20:20 後，扣晚餐）|
| 六 | 0h | 0 | 0h | **全天**（建議 50% 休息／興趣、50% 進度）|
| 日 | 0h | 0 | 0h | **全天**（建議 50% 休息／興趣、50% 進度）|

> [!note] 三個關鍵校正
> 1. **週三從「最空」變「中等忙」** — 加了健身 1.5h + 打工 2h = 3.5h 額外責任
> 2. **週四變最空** — 動物行為學平時不鎖、線代只剩 1 節，午後 6-8h 是真正的黃金時段
> 3. **週五午後 15:30-18:20 變彈性** — 非考前可挪做其他主科（如生產計劃、資料庫加碼）；5/15-5/22、6/1-6/12 兩段衝刺期必鎖會計／期末科目

## 10. 給 prompt 用的預設值

當下游 prompt 沒明確指定時，使用以下預設：
- **預設能量等級**：依時段查第 4 節
- **預設可用時間**：依日期查第 9 節
- **預設責任**：本檔第 5 + 6 節
- **預設充電活動**：本檔第 7 節（每天至少 30 分鐘）
- **進度追蹤資料源**：規劃中分配時數（**非實際完成時數**）
