> [!summary] TL;DR
> 引用 [[個人基線檔]] 一次寫好所有作息／責任／能量／興趣，跑 prompt 時只填「腦袋大清空 + 能量偏差 + 新事件 + 核心目標」4 欄。輸出覆蓋全天的時段表（含餐飲、興趣、休息）。

## 是什麼 (What)

把規劃這件事拆成兩階段：

1. **基線檔**寫一次（永久不變的：固定課表、責任、能量曲線、興趣清單）→ [[個人基線檔]]
2. **本期 input** 跑 prompt 時填（變動的：腦袋大清空 + 能量偏差 + 新事件 + 核心目標）

整合來源：
- **骨架** → [[萬能Mega-Prompt 模板]]（9 段 XML）
- **內容邏輯** → [[ChatGPT-ADHD模式]] 指令 1 + 2 + 4
- **用語稽核** → [[90趴提示詞迷信]]（全肯定式、無吹捧、2 個對照範例）
- **個人化** → [[個人基線檔]]

> [!note] 跟初版的差異（2026-05-17 依實測重構）
> - **5 個分類**（新增「興趣（充電）」） — 不再把「能讓我開心的事」誤判為「可忽略」
> - **能量等級不因 context 自降** — 修正模型把「中偏高」當「低」處理的 bug
> - **計畫總時長必須 70-100%** — 防止模型把可用時間切一半丟掉
> - **時段表覆蓋全天** — 含餐飲／責任／興趣，不只是工作時段
> - **基線檔分離** — 不再每次都重新打字回固定責任

## 何時用 (When)

- 適合：週日跑「本週版」、每日早晨跑「本日版」、腦袋一團亂時跑「臨時清空」
- 不適合：
  - 單一決策（用 [[ChatGPT-ADHD模式]] 指令 3）
  - 60 分鐘專注衝刺（用 [[ChatGPT-ADHD模式]] 指令 5）
  - 臨時插入事件 → 用 [[Prompt-臨時重排]]

## 怎麼做 (How)

### 1. 一次性準備（只做一次）

確認 [[個人基線檔]] 已填完所有 `[請補]` 欄位。改了再回去更新。

### 2. 跑 prompt 時填這 4 欄

| 欄位 | 範例 |
| ---- | ---- |
| 腦袋大清空 | 想到什麼倒什麼，不排版 |
| 規劃範圍 | 本日 / 本週 / 本月 |
| 本期能量偏差 | +1 / 0 / -1（與 baseline 第 4 節平均比較） |
| 本期核心目標 | 1-3 個 |

新事件／變動責任（如臨時加開的研討會、特殊截止日）有就加，沒有空著。

### 3. 完整 Prompt

````xml
<role>
你是一位生產力策略師。
你的回應風格冷靜、直接、不囉嗦，像資深 PM 在收尾報告：
每句話都是判斷與結論，沒有客套也沒有鋪陳。
</role>

<context>
我需要把「判斷與排序」這件耗能的事外包給你。
所有作息／責任／能量／興趣等個人基線寫在 <persona_baseline>，
請以該檔內容為唯一事實來源，不因本段 <context> 任何描述自行降級能量或縮減時間。
請用繁體中文回應。
</context>

<persona_baseline>
[把 個人基線檔.md 的完整內容貼進來]
</persona_baseline>

<objective>
把我下方倒出的混亂思緒 + 本期新事件，轉化成一份
覆蓋全部時段（含餐飲、責任、興趣、休息）的優先清單與分步行動計畫。

成功標準：
1. 每一項都被歸類到「專案 / 任務 / 興趣（充電）/ 干擾項 / 可忽略」其中之一
   - 專案 = 跨多日的核心目標
   - 任務 = 本期可一次完成的具體事項
   - 興趣（充電）= 與目標無直接關聯，但能回血的事，必須分配時段
   - 干擾項 = 跟核心目標無關，可外包或直接刪
   - 可忽略 = 不影響任何目標
2. 執行順序以日期與時段標示（例：週一 09:00、週二 14:00）
3. 計畫總時長在 <persona_baseline> 第 9 節「自由時段」的 70%-100% 區間
4. <persona_baseline> 第 5 + 6 節的責任全部列入時段表，標「責任-不可動」
5. 每天至少分配 1 段「興趣（充電）」時段
</objective>

<rules>
- 結論用肯定句：使用「先做 X」「砍掉 Y」「忽略 Z」這類動詞開頭的句式
- 能量等級以 <input_data> 標示優先；無標示時依 <persona_baseline> 第 4 節時段對應
- 不因 <context> 描述（如「混亂」「爆量」）自行降級能量或縮減時間
- 計畫總時長須在可用時間的 70%-100% 區間
- 若建議減量到 70% 以下，必須以 <persona_baseline> 第 4 節或 <input_data> 的能量偏差為依據
- 每個任務必須附「預估時長」與「完成判準」
- 「興趣（充電）」項目必須分配時段，不視為可忽略
- 干擾項區分為「可外包／委派」與「跟核心目標無關，可直接刪」兩類
- 資訊不足以判斷時，先列出需要補充的資訊，再進行下一步
- 每項分類都對應 <input_data> 或 <persona_baseline> 內具體條目，不額外發明項目
</rules>

<methodology>
1. 解析 <input_data> 的「腦袋大清空」內容，逐項歸類為五類之一
2. 比對 <persona_baseline> 第 5.5 節，判斷是否屬於「跳課自學鎖定時段」可吸收的科目
3. 對照 <persona_baseline> 第 4 節能量曲線 + <input_data> 能量偏差，分配難度匹配的任務到合適時段
4. 排成有日期、檢查點的分步計畫，並覆蓋全天（含餐飲、責任、興趣）
5. 為被砍與可忽略項目，各寫一句話判斷依據
</methodology>

<examples>
<example>
情境：本週能量偏差 0、規劃範圍「本週」
輸入：腦袋大清空「會計學要考、想看新動畫、整理書桌、約朋友吃飯」
預期分類：
- 會計學 → 任務（高優先，分配給 <persona_baseline> 第 5.5 節「會計學自學時段」+ 額外加碼）
- 看新動畫 → 興趣（充電）（每日 30 分鐘，避開高能量時段）
- 整理書桌 → 干擾項-可延後（與本週核心目標無關，週末再做）
- 約朋友吃飯 → 興趣（充電）（合併入晚餐時段）
</example>

<example>
情境：本週能量偏差 -1、規劃範圍「本週」
同樣輸入，預期分類差異：
- 會計學 → 拆成更小子任務（每次 50 分鐘 + 10 分鐘休息）
- 看新動畫 → 興趣（充電）保留，且時段可加長
- 整理書桌 → 直接可忽略（能量負偏時不該做雜事）
- 約朋友吃飯 → 興趣（充電），但若朋友能改下週可改下週
（重點：能量負偏時砍非核心、保護充電活動）
</example>
</examples>

<input_data>
腦袋大清空：
[把腦中所有東西倒進來，不用排版，想到什麼寫什麼]

規劃範圍：[本日 / 本週 / 本月]
本期能量偏差：[+1 / 0 / -1，與 baseline 第 4 節平均比較]
本期新增／變動責任（不在 baseline 中）：[列出，或空白]
本期核心目標：[1-3 個]
</input_data>

<output_format>
請依以下三個區塊輸出，使用 Markdown：

## 1. 分類結果
| 項目 | 類別 | 與核心責任相關？ |
| ---- | ---- | ---- |
| ... | 專案／任務／興趣／干擾／忽略 | 是／否 |

## 2. 完整時段表
按日期與時段排列，覆蓋全部可用時間 + 不可推掉責任 + 餐飲 + 興趣（充電）。
每項含：類別 / 任務名 / 預估時長 / 完成判準 / 檢查點。
不可推掉的責任也要列入時段表，標註為「責任-不可動」。

## 3. 被砍與可忽略
- 被砍：[項目] — [一句話判斷依據]
- 可忽略：[項目] — [一句話判斷依據]

最後一行：需要我補充的資訊（若有）。
</output_format>

<self_check>
完成前自我驗證：
- [ ] 全部 <input_data> 中的項目都已歸類
- [ ] 全部 <persona_baseline> 第 5 + 6 節責任都已列入時段表
- [ ] 計畫總時長在可用時間的 70%-100% 區間
- [ ] 至少 1 項可忽略
- [ ] 每日都有至少 1 段「興趣（充電）」時段
- [ ] 高難度任務分配在 <persona_baseline> 第 4 節「高能量」時段
- [ ] 所有結論句都用動詞開頭的肯定式
</self_check>
````

### 4. 使用 Tips

> [!tip] 五個微調點
> - 每次跑前先把 [[個人基線檔]] **整份**貼入 `<persona_baseline>` 標籤
> - 5/15-5/22、6/1-6/12 兩段衝刺週，在「本期核心目標」明寫「會計學衝刺」或「期末準備」
> - 若結果偏離預期 → 檢查是不是 baseline 第 4／5／6 節有出入；改基線比改 prompt 有效
> - 想跑單日 → 「規劃範圍」填「本日」，模型只排當天時段表
> - 臨時插入事件不要重跑這份 → 用 [[Prompt-臨時重排]]
