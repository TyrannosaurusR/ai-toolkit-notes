## 是什麼 (What)

[techtip_s](https://www.threads.com/@techtip_s) 整理的 5 條 ChatGPT 指令，針對「腦袋一團亂、不知道先做什麼」情境設計。把判斷與排序這件耗能的事丟給模型，自己只負責**倒出原料**與**執行結果**。

> [!note] 主貼文原文
> 「ChatGPT 有一個『ADHD 模式』蠻誇張的。如果你常常覺得腦袋一團亂、待辦事項堆到爆、不知道該先做什麼，這幾個指令能直接幫你把混亂變成清單。」

## 何時用 (When)

- 適合：待辦清單堆到看不下去、想法雜亂無法開工、需要外部幫忙排序

## 怎麼做 (How)

### 1. 腦袋大清空整理

把腦中所有東西倒出來 → 模型分類成**專案 / 任務 / 干擾項** + 排優先順序 + 標出可直接忽略項。

```
請扮演一位生產力策略師。以下是我腦中所有的東西：[腦袋大清空內容]。請把它們整理成專案、任務和干擾項。請排出優先順序，並告訴我哪些可以直接忽略。
```

需填入：
- `[腦袋大清空內容]` — 想到什麼倒什麼，不用排版

### 2. 實際可行的行動規劃

給定**有限資源**（時間、能量、責任），讓模型回推一個務實的計畫，避免理想化的 to-do list。

```
根據我可用的時間 [每天 X 小時]、能量等級 [低／中／高] 和我的責任 [清單]，請幫我建立一個實際可行的計畫，去達成 [目標]。
```

需填入：
- `[每天 X 小時]` — 真實能投入的時間
- `[低／中／高]` — 當前能量狀態
- `[清單]` — 不可推掉的責任（家庭、本職、固定會議等）
- `[目標]` — 想達成的事

### 3. 決策簡化器

二選一卡住時，從**長期價值、可逆性、機會成本**三個固定維度比較，最後逼模型給明確建議。

```
我卡在 [選項 A] 和 [選項 B] 之間。請從長期價值、可逆性和機會成本這三個角度分析兩個選項。然後給我一個明確的建議。
```

需填入：
- `[選項 A]` / `[選項 B]` — 兩個具體選項

### 4. 混亂變清晰系統

整體情況混亂時，要求模型輸出**逐步行動計畫**，並附上優先順序、截止日期、檢查點。

```
請把這個亂七八糟的情況變成一個簡單的逐步行動計畫，包含優先順序、截止日期和檢查點：[情況]。
```

需填入：
- `[情況]` — 把目前的處境完整描述出來

### 5. 專注衝刺建構器

針對單一任務設計 **60 分鐘專注衝刺**：拆階段 → 定規則 → 明確列出要移除/避開的干擾。

```
請為 [任務] 設計一個 60 分鐘的專注衝刺。請把它拆成幾個階段、定義規則，並明確告訴我該移除或避開什麼。
```

需填入：
- `[任務]` — 要在這 60 分鐘內推進的具體事項
