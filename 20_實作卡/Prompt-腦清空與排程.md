> [!summary] TL;DR
> 把「腦袋一團亂、待辦堆到爆」的狀態外包給 ChatGPT，輸出有日期、時段、判斷依據的優先清單。Mega-Prompt 9 段骨架 + ADHD 模式指令 1/2/4 + 90% 迷信卡的用語稽核 一次整合。

## 是什麼 (What)

一份**可直接複製、填 5 個欄位就能用**的完整 prompt，把三張既有卡片的核心融合在單一範本裡：

- **骨架**來自 [[萬能Mega-Prompt 模板]]（9 段 XML 結構）
- **內容**來自 [[ChatGPT-ADHD模式]] 的指令 1（腦袋大清空）+ 2（資源約束規劃）+ 4（混亂變清晰）
- **用語**經 [[10_概念卡/90% 的「提示詞技巧」都是迷信]] 稽核 — 全部肯定式、role 不吹捧、提供 2 個對照示例

> [!note] 為什麼不放入指令 3 與 5
> 指令 3（A/B 決策）與指令 5（單一任務 60 分鐘衝刺）解決的是不同子問題，硬塞會稀釋核心目標。要用那些情境時，直接套 [[ChatGPT-ADHD模式]] 的單命令版更俐落。

## 何時用 (When)

- 適合：腦袋一團亂、待辦堆爆、不知道先做什麼；需要一次排定本週工作
- 不適合：（待補 — 跑過實際情境後再寫）

## 怎麼做 (How)

### 1. 最小可用輸入

只需填 `<input_data>` 內的 5 個欄位：

| 欄位 | 範例 |
| ---- | ---- |
| 腦袋大清空 | 隨意倒，不用排版 |
| 可用時間 | 每天 3 小時，本週共 5 天 |
| 能量等級 | 低 / 中 / 高 |
| 不可推掉的責任 | 早會、接小孩、週五客戶會議 |
| 本週核心目標 | 1-3 個 |

### 2. 完整 Prompt

````xml
<role>
你是一位生產力策略師。
你的回應風格冷靜、直接、不囉嗦，像資深 PM 在收尾報告：
每句話都是判斷與結論，沒有客套也沒有鋪陳。
</role>

<context>
我現在的狀態：腦袋一團亂、待辦事項堆到爆、不知道該先做什麼。
我需要把「判斷與排序」這件耗能的事外包給你，
自己只負責倒出原料與後續執行。請用繁體中文回應。
</context>

<objective>
把我下方倒出的混亂思緒，轉化成一份
「可在限定時間與能量下直接開工」的優先清單與分步行動計畫。

成功標準：
1. 每一項都被歸類到「專案 / 任務 / 干擾項 / 可忽略」其中之一
2. 執行順序以日期與時段標示（例：週一 09:00、週二 14:00）
3. 行動計畫總時長 ≤ 我提供的可用時間
4. 至少標出 1 項可直接忽略的事
</objective>

<rules>
- 結論用肯定句：使用「先做 X」「砍掉 Y」「忽略 Z」這類動詞開頭的句式
- 計畫總時長 ≤ 可用時間，多出來的項目進「被砍」區塊
- 能量等級為「低」時，優先安排「低決策成本、明確完成標準」的任務
- 干擾項區分為「可外包／委派」與「可延後到下週」兩類
- 每個任務必須附「預估時長」與「完成判準」
- 資訊不足以判斷時，先列出需要補充的資訊，再進行下一步
- 每項分類都對應 <input_data> 內具體條目，不額外發明項目
</rules>

<methodology>
1. 解析 <input_data> 的「腦袋大清空」內容，逐項歸類為
   「專案 / 任務 / 干擾項 / 可忽略」
2. 對照責任清單，標出哪些項目跟核心責任直接相關
3. 依可用時間與能量等級，挑出本週能實際完成的子集
4. 將子集排成有日期、檢查點的分步計畫
5. 為被砍與可忽略項目，各寫一句話的判斷依據
</methodology>

<examples>
<example>
情境：能量「中」、每天 3 小時
輸入「下週要交報告、想學日文、洗衣機壞了、媽媽生日、回信給客戶 A、研究新筆電」
預期分類：
- 報告／客戶回信 → 任務（高優先，本週工作時段）
- 洗衣機 → 干擾項-可外包（叫師傅，10 分鐘安排）
- 媽媽生日 → 任務（進日曆，避開工作時段）
- 想學日文／研究新筆電 → 可忽略（一句話：與本週核心目標無關）
</example>

<example>
情境：能量「低」、每天 1 小時（同樣輸入）
預期分類差異：
- 報告 → 拆成小子任務（例：先列大綱 30 分鐘），保留為本週任務
- 客戶回信 → 任務（決策成本低，能量低時優先做）
- 媽媽生日 → 任務（買禮物用清單，避開創意決策）
- 洗衣機／想學日文／研究新筆電 → 全進可忽略或延後
（重點：能量低時，砍量會比能量中時大）
</example>
</examples>

<input_data>
腦袋大清空：
[把腦中所有東西倒進來，不用排版，想到什麼寫什麼]

可用時間：[每天 X 小時，本週共 Y 天]
能量等級：[低 / 中 / 高]
不可推掉的責任：[家庭、本職、固定會議等]
本週要達成的核心目標：[1-3 個]
</input_data>

<output_format>
請依以下三個區塊輸出，使用 Markdown：

## 1. 分類結果
| 項目 | 類別 | 與核心責任相關？ |
| ---- | ---- | ---- |
| ... | 專案／任務／干擾／忽略 | 是／否 |

## 2. 本週行動計畫
按日期與時段排列，每項含：任務名 / 預估時長 / 完成判準 / 檢查點

## 3. 被砍與可忽略
- 被砍：[項目] — [一句話判斷依據]
- 可忽略：[項目] — [一句話判斷依據]

最後一行：需要我補充的資訊（若有）。
</output_format>

<self_check>
完成前自我驗證：
- [ ] 全部 <input_data> 中的項目都已歸類
- [ ] 計畫總時長 ≤ 可用時間
- [ ] 至少標出 1 項可忽略
- [ ] 能量等級為「低」時，所選任務皆屬「低決策成本」
- [ ] 所有結論句都用動詞開頭的肯定式（先做／砍掉／忽略／延後）
</self_check>
````

### 3. 使用 Tips

> [!tip] 三個微調點
> - **能量等級欄位最關鍵**：標「低」時模型會避開高決策成本任務，這是它最不靠直覺的設計
> - **項目被砍太兇** → 把 `<rules>` 第二條改成「總時長超出時告知我並列出取捨選項」
> - **想跑單一場景**（只決策、只衝刺）→ 不用這份整合版，直接套 [[ChatGPT-ADHD模式]] 對應的單命令
